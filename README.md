# AMX PHANTOM SCREEN

سامانهٔ اشتراک‌گذاری صفحه با رضایت کاربر، برای نمایش در داشبورد مرورگر. رابط فارسی RTL با ظاهر مشکی و سبز نئونی.

## وضعیت واقعی قابلیت‌ها

- داشبورد محافظت‌شده با رمز مدیر و نشست ذخیره‌شده در SQLite.
- ساخت QR و لینک اتاق با توکن تصادفی جدید در هر بار راه‌اندازی سرور.
- ثبت ماندگار دستگاه‌ها و تاریخچهٔ رویدادها در SQLite.
- سیگنال‌دهی WebSocket و اسکلت اتصال WebRTC با STUN.
- صفحهٔ گوشی که فقط پس از اقدام مستقیم کاربر `getDisplayMedia()` را فراخوانی می‌کند.
- هیچ ضبط مخفی یا دورزدن مجوز سیستم‌عامل وجود ندارد.

**محدودیت مهم:** اشتراک‌گذاری صفحه از طریق مرورگر در همهٔ گوشی‌ها پشتیبانی نمی‌شود؛ به‌ویژه مرورگرهای موبایل ممکن است `getDisplayMedia()` را ارائه نکنند. برای استفادهٔ واقعی، HTTPS و مرورگر سازگار لازم است. تست خودکار WebRTC چنددستگاهی و TURN در این بسته انجام نشده است. تنظیم TURN باید با اعتبارنامه‌های کوتاه‌عمر و امن انجام شود؛ هرگز راز ثابت TURN را در کد کلاینت قرار ندهید.

## نیازمندی‌ها

- Node.js 20 یا جدیدتر
- npm
- مرورگر مدرن؛ برای اشتراک‌گذاری صفحه HTTPS لازم است (به‌جز localhost در توسعه)

## نصب و اجرا در چهار دستور

در PowerShell ویندوز، ابتدا ZIP را استخراج کن و وارد پوشهٔ پروژه شو. سپس این چهار دستور را اجرا کن:

```powershell
npm install
Copy-Item .env.example .env
notepad .env
npm start
```

در فایل `.env`، مقدار `DASHBOARD_PASSWORD` را به یک رمز طولانی و یکتا (حداقل ۱۶ نویسه) و `SESSION_SECRET` را به یک رشتهٔ تصادفی حداقل ۳۲ نویسه تغییر بده؛ ذخیره کن و Notepad را ببند. دستور چهارم سرور را اجرا می‌کند. اگر سرور پس از تغییر `.env` هنوز اجرا نشده، `npm start` را بزن.

صفحهٔ داشبورد در `http://127.0.0.1:3000` باز می‌شود. مقدار پیش‌فرض HOST فقط روی همان رایانه قابل دسترسی است.

## اتصال گوشی‌ها

1. برای تست محلی، لپ‌تاپ و گوشی باید روی یک شبکه باشند؛ برای گوشی‌ها معمولاً به HTTPS و یک آدرس قابل دسترس از شبکه نیاز است.
2. سرور را روی آدرس شبکهٔ محلی اجرا کن (`HOST=0.0.0.0` در `.env`) و فایروال را فقط به‌اندازهٔ لازم تنظیم کن.
3. برای اینترنت عمومی، روی هاست Node.js با HTTPS مستقر کن؛ آدرس HTTP محلی را به‌عنوان اتصال اینترنتی معرفی نکن.
4. وارد داشبورد شو، QR را با گوشی اسکن کن، نام دستگاه را وارد کن و «اتصال» را بزن.
5. روی گوشی «انتخاب صفحه و شروع اشتراک‌گذاری» را بزن و در پنجرهٔ رسمی مرورگر صفحه‌ای را انتخاب کن.
6. در داشبورد «درخواست نمایش زنده» را بزن. برای هر نشست، مالک گوشی باید خودش اشتراک‌گذاری را آغاز کند. برای توقف، دکمهٔ توقف را بزن یا اشتراک‌گذاری را از کنترل‌های مرورگر متوقف کن.

## راه‌اندازی برای اینترنت / Render

1. مخزن را به سرویس وب Node.js وصل کن.
2. Build command: `npm install`
3. Start command: `npm start`
4. متغیرهای `DASHBOARD_PASSWORD` و `SESSION_SECRET` را در بخش Environment سرویس تنظیم کن؛ `COOKIE_SECURE=true` بگذار.
5. برای پایگاه دادهٔ SQLite پایدار، دیسک دائمی را به مسیر `data` متصل کن؛ بدون دیسک پایدار ممکن است داده‌ها در استقرار مجدد از بین بروند.
6. WebRTC ممکن است برای بعضی شبکه‌ها به TURN نیاز داشته باشد. این نسخه در حال حاضر STUN عمومی دارد و TURN از پنل به‌صورت پویا تزریق نشده؛ پس اتصال بین همهٔ شبکه‌ها تضمین‌شده نیست.

## امنیت

- رمز مدیر و راز نشست فقط از `.env` خوانده می‌شوند.
- فایل `.env` نباید commit شود.
- QR اتاق فقط تا راه‌اندازی مجدد سرور معتبر است.
- ثبت دستگاه به معنی رضایت دائمی نیست.
- صفحهٔ اشتراک‌گذاری از API رسمی مرورگر استفاده می‌کند؛ امکان دورزدن مجوزها وجود ندارد.

## تست

```powershell
npm test
```

این تست‌ها اعتبار قالب شناسه و تصادفی بودن توکن را بررسی می‌کنند؛ آن‌ها جایگزین تست دستی مرورگر، WebRTC، HTTPS، چنددستگاهی و TURN نیستند.
